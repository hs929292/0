# 제갈량 상소문

매일 아침 7시, 또는 컴퓨터를 켤 때(하루 한 번) 제갈량 말투의 조언 창이 뜹니다.

- **第一疏 클로드코드 병법** (2,000자 이상): 초보를 위한 클로드코드 쓰는 법, 10편 중 하루 4편
- **第二疏 천하의 길** (3,000자 이상): 사업과 삶의 방향, 10편 중 하루 4편
- **오늘의 한 걸음**: 바로 할 수 있는 작은 행동 하나. 체크하면 연속 일수가 쌓입니다.

날짜마다 다른 조합이 나오고(조합 수 약 4만 가지), 같은 날 다시 열면 같은 글이 나옵니다. ‹ 지난 상소 / 다음 상소 › 버튼으로 다른 날 글도 볼 수 있습니다.

## 설치

이 `sangso` 폴더를 내 컴퓨터의 계속 둘 위치(예: `문서\sangso`)에 복사한 뒤:

**Windows**: `install-windows.bat`을 더블클릭하세요.
- 매일 07:00 작업 스케줄러에 등록 (그 시각에 PC가 꺼져 있었으면 켜진 뒤 바로 실행)
- 로그인할 때 시작프로그램으로 실행
- 바탕화면에 다시 열기 바로가기 생성
- 7시와 로그인 중 먼저 온 쪽에서 하루 한 번만 뜹니다.
- 지우기: `uninstall-windows.bat`

**macOS**: 터미널에서 `bash install-mac.sh`

폴더를 옮기면 설치를 한 번 더 해 주세요.

## 글 고치기

모든 글은 `content.js`에 있습니다. 목표나 상황이 바뀌면 클로드코드에게
"sangso/content.js의 profile과 상소 내용을 내 최신 상황에 맞게 고쳐 줘"라고 시키면 됩니다.
