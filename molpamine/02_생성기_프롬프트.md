# 전자책 생성기 v0 – 6단계 프롬프트

Claude 대화창에 순서대로 붙여넣으면 됩니다. `{ }` 부분만 바꾸고, **앞 단계 답을 다음 단계에 그대로 붙여넣는 것**이 핵심입니다.
몰파민 책을 쓰면서 실제로 써 보고 고친 버전으로 계속 업데이트합니다. (이 6개가 나중에 앱의 엔진이 됩니다)

---

## ① 팔리는 주제
```
나는 아래 경험을 가진 사람이야. 이걸로 전자책을 쓰려고 해.
- 알고 싶었던 것: {}
- 재밌게 할 수 있는 분야: {}
- 겪은 약점·고민: {}
- 이제는 아닌 상처: {}
- 지금 힘든 것: {}

1) 다섯 항목이 겹치는 핵심 메시지를 한 문장으로 뽑아줘.
2) "이 책을 다 읽은 사람은 ___ 할 수 있게 된다" 문장 3개 (실용형/회복형/정체성형). 측정 가능한 결과를 넣어줘.
3) 제목+부제 후보 3개.
```

## ② 주제 리서치
```
책 제목: {}  /  약속 문장: {}
이 주제로 책을 쓸 때
1) 근거로 쓸 수 있는 연구·개념 5개 (연구자 이름, 연도, 한 줄 설명)
2) 대중적으로 퍼졌지만 과학적으로 약하거나 틀린 주장 3개와 대신 쓸 표현
3) 비슷한 책들과 다르게 내 경험으로 차별화할 지점 3개
확실하지 않은 건 "확인 필요"라고 표시해줘.
```

## ③ 목차 설계
```
제목·약속 문장·리서치 결과: {}
내 다섯 항목: {}
전체 25~30쪽 전자책 목차를 만들어줘.
- 프롤로그(내 경험) → 원리 → 해석 바꾸기 → 실천 루틴 → 에필로그 흐름
- 각 장마다: 제목 / 이 장을 읽으면 얻는 것 1줄 / 내 항목 중 어떤 걸 쓰는지
```

## ④ 원고 집필 (장마다 반복)
```
책: {제목}  /  약속 문장: {}  /  목차: {}
이번에 쓸 장: {장 제목}
내 실제 경험 메모: {3~5줄, 날것 그대로}

규칙
- 독자에게 말하듯 "~요"체, 문장은 짧게
- 시작은 내 경험 장면, 그다음 뇌과학 설명 1~2개(쉬운 비유), 마지막은 오늘 해볼 행동 1개
- A4 3~4쪽 분량
- 의학적 진단·치료처럼 들리는 표현 금지
- 내 경험 메모에 없는 사실을 지어내지 말 것. 필요하면 [저자 확인: ...]로 비워둘 것
- 구조: 장면 → "나는 왜 이럴까?" 같은 질문 → 해석 뒤집기(굵게 한 문장) → 근거 1개 → 다음 장으로 넘기는 한 줄
- 맨 아래에 '근거 메모'(연구자, 연도, 제목)를 따로 달 것
```
> v1.4 (3장에서 검증): 저자의 '잘 되는 경험'(예: 게임)과 '안 되는 일'(공부)을 같은 기준 표로 비교하면 정의 장이 선명해짐. 장 끝의 감정 단서를 다음 장 주제로 넘기면 연결이 자연스러움.
> v1.3 (2장에서 검증): 3줄 메모를 '직전 기분 → 하는 동안 기분 → 끝난 뒤 기분'으로 받으면 원리 장의 뼈대가 자동으로 생김. 개념 비교는 표 1개로 정리.
> v1.2 (1장에서 검증): 설명 장은 '내 오해 → 뒤집힌 해석 → 소제목 2~3개로 원리 → 오늘의 몰파민 행동(번호 3단계) → 다음 장 질문' 순서가 잘 작동함. 근거는 장마다 2~4개.
> v1.1 (프롤로그에서 검증): 경험 메모 3줄만으로도 초안이 나옴. '해석 뒤집기 한 문장'이 글의 중심을 잡아줌.

## ⑤ 표지 디자인

```
그리고 고른 콘셉트로 표지를 HTML 한 장(A4 비율)으로 만들어줘.
```
