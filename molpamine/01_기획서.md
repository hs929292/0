# 몰파민 – 폰에 빼앗긴 뇌를 몰입으로 되찾는 법

## 확정된 것
| 항목 | 내용 |
|---|---|
| 제목 | **몰파민** |
| 부제 | 폰에 빼앗긴 뇌를 몰입으로 되찾는 법 |
| 약속 문장 | 이 책을 다 읽은 사람은 **폰 도파민 대신 몰파민으로 하루 1시간 깊이 몰입**할 수 있게 된다. |
| 핵심 개념 | 도파민은 하나, 얻는 길은 두 개. 빠른 길(쇼츠·스크롤) vs 느린 길(몰입 = 몰파민). 같은 물질도 뇌가 어떤 길로 해석하느냐에 따라 삶이 달라진다. |
| 저자의 자격 | 우울·불안·대인기피·브레인포그를 지나온 사람. 정보가 아니라 "지나온 길"을 쓴다. |
| 안내 문구 | 이 책은 의학적 진단·치료를 대신하지 않습니다. 저자의 경험과 공개된 뇌과학 연구를 바탕으로 한 이야기입니다. |

## 독자 (한 사람으로)
- 20~30대, 퇴근하고 누우면 쇼츠 2시간, 자기 전 "오늘도 아무것도 못 했다"며 자책하는 사람
- 집중이 안 되는 걸 "의지가 약해서"라고 생각하는 사람

## ② 리서치: 쓸 수 있는 근거 / 피할 주장
**써도 되는 것 (출처 확인 후 인용)**
- 도파민은 "쾌락 물질"이라기보다 **원하게 만들고 다음 보상을 예측하는** 물질에 가깝다 (보상 예측 오차 연구, Schultz).
- 몰입(flow)은 **과제 난이도와 실력이 맞을 때** 잘 일어난다 (칙센트미하이).
- 일을 바꿀 때 앞 일에 주의가 남아 집중이 떨어진다 – **주의 잔여(attention residue)** (Sophie Leroy, 2009).
- 생각을 다르게 해석하는 연습(인지 재평가)이 감정 반응을 바꾼다 (Gross의 감정 조절 연구).

**피할 것 (반박당하기 쉬움)**
- "도파민 디톡스로 도파민을 끊는다" → 도파민은 끊을 수 없다. 대신 "얻는 길을 바꾼다"로 쓴다.
- "몰입하면 신경물질이 4단계로 나온다" 같은 근거 불명확한 공식.
- "브레인포그"를 의학 진단처럼 쓰는 것 → "머리가 뿌옇게 느껴지는 상태"라는 생활 표현으로 쓴다.
